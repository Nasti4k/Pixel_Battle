# Pixel Battle

Совместная пиксельная рисовалка в реальном времени. Несколько пользователей могут одновременно рисовать на одном холсте — каждый пиксель мгновенно отображается у всех подключённых клиентов. Нарисованное сохраняется в файл, поэтому холст восстанавливается после перезапуска сервера.

## Возможности

- **Общий холст** — все участники рисуют на одном canvas 1200×740 px
- **Синхронизация в реальном времени** — изменения передаются через WebSocket
- **Автосохранение** — каждый пиксель записывается в JSON-файл
- **Восстановление состояния** — при подключении клиент получает все ранее нарисованные пиксели
- **Палитра из 11 цветов** — красный, оранжевый, жёлтый, зелёный, голубой, синий, фиолетовый, серый, коричневый, чёрный, белый

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку проекта:

```bash
git clone <url-репозитория>
cd Pixel_Battle
```

2. Создайте виртуальное окружение (рекомендуется) и установите зависимости:

```bash
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # Linux / macOS

pip install fastapi uvicorn jinja2
```

3. Запустите сервер из папки `app`:

```bash
cd app
uvicorn main:app --reload
```

4. Откройте в браузере:

```
http://127.0.0.1:8000
```

Страница автоматически перенаправит на `/main_page` с холстом для рисования.

## Как пользоваться

1. Выберите цвет, нажав на кнопку в палитре сверху.
2. Кликните по холсту — в этой точке появится пиксель размером 10×10 px.
3. Повторный клик по той же ячейке перекрасит её в новый цвет.
4. Откройте приложение в нескольких вкладках или на разных устройствах — рисунок будет синхронизироваться между всеми клиентами.

## API

| Метод / протокол | Путь         | Описание                              |
|------------------|--------------|---------------------------------------|
| GET              | `/`          | Перенаправление на `/main_page`       |
| GET              | `/main_page` | Страница с холстом                    |
| WebSocket        | `/ws`        | Обмен пикселями в реальном времени    |

Клиент подключается к WebSocket автоматически — адрес берётся из URL страницы, на которой открыто приложение:

```javascript
const wsProtocol = window.location.protocol === 'https:' ? 'wss:' : 'ws:';
let socket = new WebSocket(`${wsProtocol}//${window.location.host}/ws`);
```

Поэтому при локальном запуске используется `ws://127.0.0.1:8000/ws`, а после деплоя на HTTPS — `wss://ваш-домен/ws`. Менять адрес в коде не нужно.

При рисовании клиент отправляет JSON:

```json
{
  "id": "6020",
  "glob_color": "rgb(255, 0, 0)",
  "pozic_x": 60,
  "pozic_y": 20
}
```

- `id` — уникальный идентификатор ячейки (конкатенация координат X и Y)
- `glob_color` — цвет в формате `rgb(r, g, b)`
- `pozic_x`, `pozic_y` — координаты верхнего левого угла пикселя

Сервер рассылает это сообщение остальным клиентам и сохраняет (или обновляет) запись в `app/repository/data_pixels.json`.
